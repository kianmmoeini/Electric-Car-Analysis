# Electric Car Analysis 🚗⚡

A data analysis project focused on exploring and understanding electric vehicle data using Python.

## Overview

This project analyzes electric car datasets to discover patterns, trends, and relationships between different vehicle specifications.

The goal is to extract meaningful insights from electric vehicle data through data cleaning, exploration, visualization, and statistical analysis.

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Handling missing values
- Statistical analysis
- Data visualization
- Finding relationships between electric vehicle features
- Generating insights from EV datasets

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Analysis

The project explores different electric vehicle attributes such as:

- Battery capacity
- Driving range
- Charging information
- Vehicle specifications
- Performance metrics
